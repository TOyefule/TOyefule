## 👨🏾‍💻 About Me

Software Engineer with 7+ years building secure, scalable systems in healthcare and regulated environments. I specialize in backend development, data engineering, and cloud infrastructure (AWS & Azure), with a strong focus on interoperable systems using REST APIs and FHIR standards. I've led production support and modernization efforts across EMR-integrated systems, billing workflows, and clinical operations.

- 🩺 Currently consulting as a **Data Engineer**, designing HIPAA-compliant data platforms and billing analytics for healthcare organizations
- 🏥 Hands-on experience with EMR ecosystems (**Epic, Cerner**), **FHIR** (HAPI-FHIR), and REST-based integration services
- 🧭 Strong background leading IT teams, production support, and technical documentation in live clinical environments
- 🤝 Open to collaborating on healthcare data platforms, interoperable APIs, and AI/LLM-powered tools for clinicians and operations
